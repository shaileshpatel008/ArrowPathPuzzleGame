# Play Store listing (draft)

**App name (30 chars max):** Arrow Path Puzzle

**Short description (80 chars max):**
Tap arrows in the right order and clear the board. A calm, clever brain puzzle.

**Full description:**

Every arrow wants out. Tap one and it slides the way it points. If the path is clear, it flies off the board. If another arrow is in the way… crash! Find the right order and clear the board.

WHY YOU'LL LOVE IT
• 200 levels across 8 chapters, from 4×4 to 9×9 boards
• A new Daily Challenge every day, with streaks and monthly badges
• Three hearts per level, so a mistake isn't the end
• Aim mode: preview a path before you fire
• Unlimited undo, plus hints that show you a safe move
• Beautiful themes, including a dark mode and a high-contrast mode
• Colour-blind friendly arrows and reduce-motion option
• Plays offline, no account needed

ARROW PATH PLUS (optional)
No ads, 3 free hints every day, every theme, replay past daily challenges and a weekly streak freeze. Available monthly, yearly or as a one-time lifetime purchase.

Relax, think ahead, and clear the path.
