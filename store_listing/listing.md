## Full description (max 4000)
Every arrow wants out. Tap one and it slides the way it points. If the path is clear, it flies off the board. If another arrow is in the way… crash! Think ahead, find the right order and clear the board.

Arrow Path Puzzle is a calm, clever logic game that is easy to learn and hard to put down. Play a quick level on the bus or relax with a long session at home.

🧩 HOW TO PLAY
• Tap an arrow to send it sliding in the direction it points
• If nothing blocks its path, it leaves the board
• If it hits another arrow, you lose a heart
• Clear every arrow to win and earn up to 3 stars

⭐ FEATURES
• 200 levels across 8 chapters, from small 4×4 boards to tricky 9×9 grids
• A new Daily Challenge every day, with streaks, streak freezes and monthly badges
• 3 hearts per level, so one mistake doesn't end your game
• Aim mode: preview an arrow's path before you tap
• Unlimited undo, plus hints that show you a safe move
• Earn free hints by clearing levels without a crash
• Beautiful themes, including a dark mode and a high-contrast mode
• Colour-blind friendly arrows and a reduce-motion option
• Satisfying animations, sounds and haptics
• Track your stats, best streak and achievements
• Plays offline, no account needed
